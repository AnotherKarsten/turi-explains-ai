Turi kann hier leider nicht starten

Du siehst gerade nur eine Vorschau, zum Beispiel aus einem Mailprogramm oder einer Dateien-App. In einer Vorschau läuft kein JavaScript, und ohne JavaScript funktioniert das Lernprogramm nicht.

  1. Speichere die Datei auf deinem Gerät (zum Beispiel im Ordner „Downloads“ oder auf dem Schreibtisch).
  2. Öffne die gespeicherte Datei mit einem richtigen Browser, zum Beispiel Safari, Chrome, Firefox oder Edge (am Computer: Rechtsklick → „Öffnen mit“).
  3. Hast du einen Link bekommen? Dann öffne den Link direkt im Browser.
  4. Auf iPad und iPhone zeigt die Dateien-App nur eine Vorschau. Öffne Turi dort am besten über einen Link in Safari.
  5. Ist JavaScript im Browser ausgeschaltet, schalte es bitte ein.

English

This is only a preview (for example from an email app), and previews cannot run JavaScript. Please save the file and open it in a real browser such as Safari, Chrome, Firefox or Edge, or open the link directly in your browser. On iPad and iPhone, open Turi via a link in Safari.
